#  Discord Multipurpose Bot

Многофункциональный Discord-бот, написанный на **Python** с использованием современной библиотеки **discord.py**. Бот обладает функциями модерации, развлечений, мини-игр, интеграцией со сторонними API и возможностью проигрывания музыки.

Это пет-проект, созданный для практики работы с асинхронным программированием, Discord API и RESTful API.

##  Основные возможности

-  Модерация: Очистка чата, кик, бан и вывод информации о сервере/пользователях.
- Музыкальный плеер: Поиск и воспроизведение аудио с YouTube прямо в голосовом канале (с использованием `yt-dlp` и `FFmpeg`).
- Развлечения и мини-игры: Орел и решка, бросок кубиков (кости), магический шар предсказаний.
- Интеграция с API: Асинхронные запросы к сторонним сервисам (генерация случайных мемов, картинок с животными, RP-команды вроде hug, pat) с помощью `aiohttp`.

## Технологии и стек

- **Язык:** Python 3.9+
- **Библиотеки:** 
  - `discord.py` (взаимодействие с Discord API)
  - `aiohttp` (асинхронные HTTP-запросы без блокировки Event Loop)
  - `yt-dlp` (скачивание аудиопотока)
  - `python-dotenv` (безопасное хранение токенов)
